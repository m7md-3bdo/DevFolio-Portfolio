## Built With

- HTML5
- CSS3 (Flexbox, media queries, CSS variables)
- Bootstrap 5.3
- JavaScript (vanilla)
- Font Awesome 6 (icons)
- Google Fonts: Playfair Display, Poppins

## Features

- Responsive layout for mobile, tablet and desktop
- Dark Bronze Gold theme with a consistent color palette
- Fixed navbar with active link highlighting while scrolling
- Hover effects on cards and project thumbnails
- Animated counters
- Contact form that opens the visitor's email app with the message filled in
- Back-to-top button
